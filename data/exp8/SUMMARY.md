# 实验8：用户行为与社区学习动力学

## 实验目标

分析 JIDI 平台上用户的学习行为模式和留存特征（论文第 6.2 节）。具体回答：
1. 用户的策略改进遵循什么样的学习曲线形态（线性/对数/幂律）？
2. 高/中/低表现用户的学习曲线有何差异？
3. 平台的用户留存率如何？哪些因素影响留存？

## 具体方法

### 数据来源
- `submission` 表：用户提交历史（user_id, create_time, 版本序列）
- `agent_history` 表：对局结果（win_flg）
- 分析范围：Top 5 多智能体环境（按策略数排序）

### Top 5 环境选择
| 环境 | env_id | 策略数 |
|------|--------|--------|
| olympics-wrestling | 74 | 4,369 |
| snakes_1v1 | 1 | 3,671 |
| snakes_3v3 | 6 | 2,673 |
| olympics-integrated | 88 | 1,023 |
| gobang_1v1 | 3 | 641 |

### 实现脚本
- `exp8_user_learning.py`（440行）

### 分析流程

#### 1. 用户学习曲线
- 对每个环境，获取所有 submission，按 (user_id, create_time) 排序
- 过滤出 >= 3 个版本提交的用户（确保有学习轨迹可分析）
- 分批查询这些用户策略的 agent_history 对局结果（每批 100 个 submission_id）
- 为每个 submission 计算胜率（基于 pairwise 对局结果）
- 对每个用户的版本-胜率序列拟合三种模型：
  - **线性**：y = ax + b（匀速改进）
  - **对数**：y = a·ln(x) + b（快速提升后趋缓）
  - **幂律**：y = a·x^b（幂律学习曲线）
- 按 R² 选择最优模型

#### 2. 分组对比
- 按最终胜率将所有用户分为高/中/低三组（各 1/3）
- 对齐版本序号，计算每组各版本的平均胜率
- 可视化三组学习曲线的形态差异

#### 3. 留存分析
- 对所有有提交记录的用户（2,249 人），计算首次提交到末次提交的时间跨度
- 统计 30/60/90 天留存率（末次 - 首次 >= 对应天数即视为留存）

## 实验结论

### 核心数据
| 指标 | 数值 |
|------|------|
| 分析涵盖的用户–环境轨迹数 | 411（376 名去重用户） |
| 成功拟合学习曲线数 | 411/411 条轨迹（100%） |
| 最优模型分布 - linear | 182 条轨迹（44.3%） |
| 最优模型分布 - log | 174 条轨迹（42.3%） |
| 最优模型分布 - power | 55 条轨迹（13.4%） |
| 30 天留存率 | 13.8%（311/2,249） |
| 60 天留存率 | 9.8%（221/2,249） |
| 90 天留存率 | 8.9%（200/2,249） |

### 各环境用户学习数据
| 环境 | 多版本用户–环境轨迹数 | 成功拟合 | 主导模型 |
|------|-------------|---------|---------|
| olympics-wrestling | 78 | 78 | linear（41） |
| snakes_1v1 | 125 | 125 | log（62） |
| snakes_3v3 | 124 | 124 | linear（51）/ log（54） |
| olympics-integrated | 53 | 53 | linear（31） |
| gobang_1v1 | 31 | 31 | log（15） |

### 关键发现
1. **学习曲线以线性和对数形态为主**：44.3% 的用户–环境轨迹最佳拟合为线性，42.3% 为对数，两者合计占 86.6%。这些比例是按最大 R² 选择模型得到的描述性统计。
2. **对数学习曲线印证"快速入门"现象**：在 snakes_1v1 和 gobang_1v1 等棋类/网格环境中，对数模型占主导，表明用户在最初几次提交中进步最快，随后进入缓慢精调阶段。这符合经典的学习曲线理论。
3. **线性改进在体育类环境中更常见**：olympics-wrestling 和 olympics-integrated 中线性模型占主导，可能因为这些环境策略空间更复杂，用户需要持续多轮迭代才能逐步提升。
4. **平台留存率偏低但符合开源评测平台特征**：30 天留存 13.8%、90 天留存 8.9%。考虑到平台面向全球学术用户群体，且无需付费，这一留存水平与 MOOC 等在线教育平台的留存率相当。
5. **留存率衰减主要在首月内发生**：30 天留存（13.8%）到 90 天留存（8.9%）的衰减幅度（约 5 个百分点）远小于首月内的流失（86.2%），说明一旦用户度过首月，后续留存趋于稳定。
6. **snakes_1v1 包含最多的多版本轨迹**（125 条），其次是 snakes_3v3（124 条）；这两个环境是该分析中最活跃的迭代场景。
